# 카타: String Calculator

문자열을 받아 숫자들의 합을 반환하는 `add(numbers: string): number` 함수를 TDD로 만든다.

**핵심 규칙**: 한 번에 STEP 하나. 항상 RED(실패 테스트) → GREEN(최소 구현) → REFACTOR 순서로.
앞 STEP 요구사항을 미리 구현하지 말 것. 테스트가 시키는 만큼만 짠다.

---

## 요구사항 (순서대로)

### STEP 1 — 빈 문자열
- `add("")` → `0`

### STEP 2 — 숫자 하나
- `add("1")` → `1`
- `add("42")` → `42`

### STEP 3 — 숫자 두 개 (쉼표 구분)
- `add("1,2")` → `3`

### STEP 4 — 개수 제한 없음
- `add("1,2,3,4,5")` → `15`

### STEP 5 — 개행도 구분자로
- `add("1\n2,3")` → `6`
  (쉼표와 개행 `\n` 둘 다 구분자로 취급)

### STEP 6 — 커스텀 구분자
- 맨 앞에 `//구분자\n` 형식으로 구분자를 지정할 수 있다.
- `add("//;\n1;2")` → `3`
- `add("//|\n4|5|6")` → `15`

### STEP 7 — 음수는 예외
- 음수가 있으면 에러를 던진다.
- `add("-1")` → throw `"음수는 허용되지 않습니다: -1"`
- 음수가 여러 개면 전부 나열: `add("2,-4,-8")` → throw `"음수는 허용되지 않습니다: -4, -8"`

### STEP 8 — 1000 초과는 무시
- `add("2,1001")` → `2`
- `add("1000,1")` → `1001` (1000은 포함, 1001부터 무시)

---

## 도전 과제 (여유 있으면)

### STEP 9 — 길이가 긴 구분자
- `add("//[***]\n1***2***3")` → `6`

### STEP 10 — 구분자 여러 개
- `add("//[*][%]\n1*2%3")` → `6`

---

## 진행 팁

- **삼각측량**: STEP 2에서 `add("1")`만 있으면 `return 1`로 통과된다.
  `add("42")`를 추가해야 진짜 파싱 로직이 필요해진다. 이렇게 예시 2개로 일반화를 유도해봐라.
- 테스트 리스트를 먼저 종이/주석에 적어두고, 하나씩 지워나가면 길을 잃지 않는다.
- GREEN이 되면 **커밋**하는 습관. 초록불 = 안전 지점.

실행: `npm test` (watch로 계속 돌리려면 `npx vitest`)
